## Step 2: Prepare Firebase Credentials

### Get Your Firebase Admin SDK JSON:

1. Go to Firebase Console: https://console.firebase.google.com/
2. Select your project: **cerpup**
3. Click **⚙️ Settings** → **Project Settings**
4. Go to **Service Accounts** tab
5. Click **Generate New Private Key**
6. Download the JSON file (keep it safe!)

### Convert JSON to Single Line:

**Option A - Using Python:**
```bash
python -c "import json; print(json.dumps(json.load(open('firebase-credentials.json'))))"
```

**Option B - Using Online Tool:**
1. Go to: https://www.text-utils.com/json-formatter/
2. Paste your JSON
3. Click "Minify"  
4. Copy the result

**You'll get something like:**
```json
{"type":"service_account","project_id":"cerpup","private_key_id":"...","private_key":"-----BEGIN PRIVATE KEY-----\n...\n-----END PRIVATE KEY-----\n","client_email":"...","client_id":"...","auth_uri":"...","token_uri":"...","auth_provider_x509_cert_url":"...","client_x509_cert_url":"..."}
```

## Step 3: Create Render Web Service

1. **Go to Render Dashboard:** https://dashboard.render.com/
2. **Click "New +"** → **"Web Service"**
3. **Connect GitHub:** 
   - Click "Connect account" if not connected
   - Select your repository: **CerpUp**
4. **Configure Service:**
   - **Name:** `cerpup` (or your preferred name)
   - **Region:** Choose closest to you
   - **Branch:** `main`
   - **Root Directory:** (leave blank)
   - **Runtime:** `Python 3`
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `gunicorn app:app`
   - **Instance Type:** `Free` (or upgrade as needed)

## Troubleshooting

### ❌ Error: "Firebase initialization failed"

**Solution:** Check `FIREBASE_CREDENTIALS_JSON` is properly formatted:
- Must be valid JSON (no line breaks in private key)
- Must be minified (single line)
- Must include ALL fields from Firebase service account JSON

**Test locally first:**
```bash
python -c "import os, json; json.loads(os.getenv('FIREBASE_CREDENTIALS_JSON'))"
```

---

### ❌ Error: "Module not found"

**Solution:** Make sure `requirements.txt` is complete:
```bash
# Check locally
pip freeze > requirements.txt
git add requirements.txt
git commit -m "Update requirements"
git push
```

---

### ❌ Error: "Application failed to respond"

**Solution:** Check Render logs:
1. Go to Render Dashboard
2. Click your service
3. Go to **Logs** tab
4. Look for Python errors

Common issues:
- Missing environment variable
- Port binding (Render handles this automatically with gunicorn)
- Database connection timeout

---

### ❌ Deployment Taking Too Long

**Solution:**
- Free tier can take 2-5 minutes
- First deployment is slowest (installing dependencies)
- Subsequent deploys are faster (cached dependencies)

If deployment breaks:

1. Go to **Render Dashboard**
2. Click your service
3. Go to **Events** tab
4. Find previous successful deploy
5. Click **"Redeploy"**

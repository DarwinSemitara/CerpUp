# Deployment Checklist for Render

## ✅ Pre-Deployment Checks

- [x] Main app renamed from `app_supabase.py` to `app.py`
- [x] Firebase code archived in `archive_firebase/` folder
- [x] Utility scripts moved to `scripts/` folder
- [x] `.gitignore` updated to exclude sensitive files
- [x] `render.yaml` configured for Supabase
- [x] `requirements-supabase.txt` has all dependencies

## 📋 Files That Will NOT Be Pushed to GitHub

These files are in `.gitignore`:
- `.env` (contains secrets)
- `firebase-credentials.json`
- `__pycache__/`
- `firebase_backup/`
- `archive_firebase/`
- `.vscode/`

## 🔑 Environment Variables to Set in Render

You MUST configure these in Render dashboard before deployment:

### Required Variables:
1. `SECRET_KEY` - Flask secret key (auto-generated by Render)
2. `SUPABASE_URL` - Your Supabase project URL
3. `SUPABASE_ANON_KEY` - Supabase anonymous key
4. `SUPABASE_SERVICE_KEY` - Supabase service role key
5. `CLOUDINARY_CLOUD_NAME` - Cloudinary cloud name
6. `CLOUDINARY_API_KEY` - Cloudinary API key
7. `CLOUDINARY_API_SECRET` - Cloudinary API secret

### Where to Find These Values:

**Supabase**:
- Go to your Supabase project dashboard
- Click "Settings" → "API"
- Copy:
  - Project URL → `SUPABASE_URL`
  - anon/public key → `SUPABASE_ANON_KEY`
  - service_role key → `SUPABASE_SERVICE_KEY`

**Cloudinary**:
- Go to Cloudinary dashboard
- Copy from the "Product Environment Credentials" section

## 🚀 Render Deployment Steps

1. **Login to Render**:
   - Go to https://dashboard.render.com/

2. **Create New Web Service**:
   - Click "New +" button
   - Select "Web Service"
   - Connect your GitHub account if not already connected
   - Select your CERP2.0 repository

3. **Configure Service**:
   - Name: `cerpup` (or any name you prefer)
   - Branch: `main`
   - Runtime: Python
   - Render will auto-detect settings from `render.yaml`

4. **Add Environment Variables**:
   - Go to "Environment" tab
   - Click "Add Environment Variable"
   - Add all 7 variables listed above
   - **Important**: Click "Save Changes" after adding each one

5. **Deploy**:
   - Click "Create Web Service" or "Manual Deploy"
   - Wait for build to complete (5-10 minutes)
   - Check logs for any errors

## ✅ Post-Deployment Verification

After deployment succeeds:

1. **Check the URL**: Visit your Render URL (e.g., `https://cerpup.onrender.com`)
2. **Test Login Page**: Should load without errors
3. **Create Admin Account**: Use the scripts if needed
4. **Test Member Login**: Login with test credentials
5. **Check Database Connection**: Try adding a research entry

## ⚠️ Common Issues and Solutions

### Issue: "No module named 'supabase'"
**Solution**: Check that `requirements-supabase.txt` is being used in `render.yaml`

### Issue: "Invalid Supabase credentials"
**Solution**: Double-check environment variables in Render dashboard

### Issue: Build fails
**Solution**: Check build logs in Render dashboard, verify Python version (3.11)

### Issue: App crashes on startup
**Solution**: Check application logs for errors, verify all environment variables are set

## System Structure

### Admin Dashboard Layout
"The CERP admin interface has a consistent layout:
- **Left Sidebar**: Main navigation menu with all sections
- **Top Header**: Page title, notifications, and user info
- **Main Content**: Current page content and features
- **Footer**: System info and quick links (on some pages)

The sidebar stays visible as you navigate, making it easy to switch between sections."

## Quick Actions

### Using Search
"Most pages have search functionality:
1. Look for the search box (usually top-right of content)
2. Type name, code, or keyword
3. Results filter automatically
4. Clear search to see all items again

Search works across faculty names, course codes, research titles, etc."

### Filtering and Sorting
"Organize data efficiently:
- **Filter**: Click filter icon, select criteria, apply
- **Sort**: Click column headers to sort ascending/descending
- **Group**: Some pages allow grouping by category
- **Date Range**: Use date pickers to limit results to specific periods

Combine filters for precise results (e.g., faculty in specific department + specific semester)."

### Exporting Data
"Export data from most pages:
1. Apply any filters you want
2. Click 'Export' button (usually near search)
3. Choose format (Excel, CSV, PDF)
4. File downloads to your computer

Exported data matches current filters and sorting."

## Common Navigation Patterns

### Viewing Details
"To see detailed information:
- **List views**: Click on an item to expand details
- **Cards**: Click anywhere on card to open
- **Tables**: Click row or 'View' icon
- **Modal windows**: Details open in overlay (close with X or click outside)

Use browser back button or 'Close' to return to list."

### Edit Mode
"To edit items:
1. Find the item (search if needed)
2. Click 'Edit' icon (usually pencil icon)
3. Form opens with current values
4. Make changes
5. Click 'Save' (or 'Cancel' to discard)
6. Confirmation message appears

Changes save immediately unless you cancel."

### Creating New Items
"To add new items:
1. Go to the relevant page
2. Click 'Add [Item]' button (usually top-right)
3. Fill in the form
4. Required fields marked with *
5. Click 'Save' or 'Create'
6. New item appears in list

Forms validate inputs before saving."

## Notifications and Alerts

### Action Notifications (Audit Trail)
"The bell icon in the header shows:
- Recent system actions
- FSR generation activity
- Important updates
- Your own actions

Click the bell to view recent actions. Badge shows count of unread items."

### CHE Assistant
"The floating lightbulb icon (bottom-right) is CHE, your AI assistant:
- Click to open chat
- Ask questions about the system
- Get help with tasks
- Quick actions for common tasks
- Available on all admin pages

Chat history persists as you navigate."

## Keyboard Shortcuts

### Common Shortcuts
"Speed up navigation with keyboard shortcuts:
- **Ctrl + K** (or Cmd + K): Quick search
- **Ctrl + /** : Open help
- **Esc**: Close modal/dialog
- **Enter**: Submit form or confirm action
- **Tab**: Navigate form fields

Some pages have additional shortcuts (look for keyboard icon)."

## Breadcrumbs and Context

### Understanding Where You Are
"Most pages show your location:
- **Page title**: Shown in header and browser tab
- **Breadcrumbs**: Home → Section → Current Page (when available)
- **Active menu item**: Highlighted in sidebar
- **URL**: Browser address shows current location

This helps you track navigation and share links with others."

## Tips for Efficient Navigation

### Pin Frequently Used Pages
"Bookmark pages you use often:
1. Navigate to the page
2. Use browser bookmark (Ctrl + D)
3. Organize in bookmarks folder
4. Quick access anytime

Consider bookmarks for: Schedule, Manage, FSR, Dashboard"

### Use Browser Tabs
"Open multiple sections simultaneously:
- Right-click menu items → 'Open in new tab'
- Work on schedules while referencing courses
- Compare data across pages
- Multi-task efficiently

Remember to save work in each tab."

### Learn the Flow
"Common workflows:
- **Schedule creation**: Courses → Faculty (Manage) → Schedule
- **FSR generation**: Member data (Manage) → Research/Extensions → FSR
- **Content updates**: Display → Preview → Publish
- **Member onboarding**: Manage → Add Member → Assign Courses → Create Schedule

Understanding these flows speeds up your work."

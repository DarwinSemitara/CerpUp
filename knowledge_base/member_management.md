# Member Management Guide

## When to Use
User asks about:
- Adding new faculty members
- Editing member information
- Managing member accounts
- Faculty roles and permissions
- Member statistics and lists

## Adding New Members

### Step-by-Step Instructions
"To add a new faculty member:
1. Go to the 'Manage' page from the admin sidebar
2. Click 'Add Member' button
3. Fill in required information:
   - Full Name (First Name, Last Name, Suffix if applicable)
   - Email Address (will be used for login)
   - Department/Unit
   - Position/Rank (Instructor, Assistant Professor, etc.)
   - Employment Status (Permanent, Temporary, Part-time)
4. Set initial credentials or send invitation
5. Click 'Save Member'

The new member can now log in and access their dashboard."

## Editing Member Information

"To update a faculty member's information:
1. Go to the 'Manage' page
2. Find the member in the list (use search if needed)
3. Click the 'Edit' icon next to their name
4. Update any fields (name, email, position, department)
5. Click 'Save Changes'

Changes take effect immediately."

## Member Roles and Access

### Admin
- Full system access
- Can manage all members
- Can generate schedules
- Can view all reports and FSRs
- Can manage system content

### IT Staff
- Limited admin access
- Can view research and extensions
- Can access dashboard statistics
- Cannot manage schedules or members

### Faculty/Member
- View own schedules and information
- Submit research and extensions
- Generate personal FSR
- Update own profile
- View announcements

## Viewing Member Statistics

"To see member statistics:
1. Go to the Dashboard page
2. View the 'Member Overview' card showing:
   - Total faculty count
   - Active members
   - Department distribution
   - Recent additions

For detailed lists, go to the Manage page where you can filter by department, status, or position."

## Common Tasks

### Deactivating a Member
"If a faculty member leaves or goes on extended leave, you can deactivate their account without deleting their records. This preserves their historical data (schedules, research, FSRs) while preventing login access."

### Resetting Passwords
"Members can reset their own passwords through the 'Forgot Password' link on the login page. Admins can also reset passwords from the Manage page if needed."

### Bulk Operations
"For adding multiple members at once, consider using the bulk import feature (if available) or contact IT support for assistance with large-scale account creation."

## Important Notes
- Email addresses must be unique (one account per email)
- Member data is linked to schedules, research, and FSR records
- Deleting a member removes all their associated data permanently
- Always verify information before saving
- Changes to member names will reflect in all schedules and reports

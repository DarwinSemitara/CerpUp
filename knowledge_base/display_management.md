# Display Management Guide

## When to Use
User asks about:
- Landing page content
- Updating homepage information
- Managing announcements
- News and events
- Public-facing content
- Hero images and banners

## What is Display Management?

"The Display page allows admins to manage public-facing content that appears on the CERP landing page. This includes:
- Hero section (welcome message and images)
- News and announcements
- Upcoming events
- Featured content
- Contact information
- Department highlights

This is what visitors and logged-out users see when they visit the CERP site."

## Accessing Display Management

"To manage landing page content:
1. Go to the 'Display' page from the admin sidebar
2. You'll see sections for different content types
3. Edit each section independently
4. Preview changes before publishing
5. Save to make content live

Only admins have access to display management."

## Managing Hero Section

### Updating Welcome Message
"To update the main welcome message:
1. Go to Display page
2. Find the 'Hero Section' card
3. Edit the headline and subtitle text
4. Keep headline under 60 characters for best display
5. Keep subtitle under 150 characters
6. Click 'Update Hero Text'

The new message appears immediately on the landing page."

### Changing Hero Image
"To update the hero background image:
1. Go to Display page
2. Click 'Change Hero Image'
3. Upload a new image (recommended: 1920x1080px, JPG or PNG)
4. Crop/adjust if needed
5. Click 'Save Image'

Use high-quality images that represent CHE/UPLB appropriately."

## Managing News and Announcements

### Adding News
"To add a news item:
1. Go to Display page
2. Click 'Add News' in the News section
3. Fill in:
   - Title (clear and descriptive)
   - Content/description
   - Date (publication date)
   - Category (announcement, event, achievement, etc.)
   - Featured image (optional)
4. Click 'Publish News'

Latest news appears at the top of the landing page."

### Editing or Removing News
"To edit existing news:
1. Find the news item in the list
2. Click 'Edit' icon
3. Update content
4. Save changes

To remove outdated news:
1. Click 'Archive' or 'Delete' icon
2. Confirm action
Archived news can be restored; deleted news is permanent."

## Managing Events

### Adding Events
"To add an upcoming event:
1. Go to Display page
2. Click 'Add Event' in the Events section
3. Fill in:
   - Event title
   - Date and time
   - Location (room/venue)
   - Description
   - Target audience
   - Registration link (if applicable)
4. Click 'Publish Event'

Events are automatically sorted by date on the landing page."

### Event Status
"Events can have different statuses:
- **Upcoming**: Displayed prominently with countdown
- **Ongoing**: Currently happening
- **Past**: Automatically moved to archive after end date
- **Cancelled**: Marked as cancelled but still visible

Update event status as needed to keep information current."

## Managing Featured Content

### Faculty Highlights
"To feature faculty achievements:
1. Go to Display page
2. Click 'Add Feature' in Faculty Highlights
3. Select faculty member
4. Add achievement/highlight description
5. Add photo (if available)
6. Set display duration
7. Publish

This showcases faculty accomplishments to visitors."

### Research Spotlights
"To spotlight research projects:
1. Add Research Spotlight
2. Select project from system or enter manually
3. Write compelling summary (avoid technical jargon)
4. Add images or infographics
5. Include keywords/tags
6. Publish

Makes research visible to the broader community."

## Content Guidelines

### Writing Style
"Keep landing page content:
- Clear and concise
- Professional but welcoming
- Free of jargon (explain technical terms)
- Grammatically correct
- Inclusive and respectful
- Aligned with UPLB/CHE branding"

### Image Guidelines
"For all images on the landing page:
- Use high resolution (at least 1200px wide)
- Keep file size reasonable (under 2MB)
- Use JPG for photos, PNG for graphics/logos
- Ensure proper licensing/permissions
- Avoid text-heavy images
- Consider mobile display (images should work at all sizes)"

### Accessibility
"Make content accessible:
- Use descriptive alt text for all images
- Ensure sufficient color contrast
- Use headings hierarchically
- Keep paragraphs short
- Provide text alternatives for visual content
- Test with screen readers if possible"

## Important Notes

### Preview Before Publishing
"Always preview changes before making them live. The preview shows:
- How content appears on desktop
- How it looks on mobile
- Link functionality
- Image loading
- Layout responsiveness"

### Content Approval
"For sensitive or major announcements:
1. Draft content first
2. Save as 'Draft' status
3. Share preview link with relevant parties
4. Get approval
5. Then publish live

This prevents premature or unauthorized announcements."

### Backup Content
"Before major updates:
1. Take screenshots of current content
2. Save text in a document
3. Note current images/files
4. This allows rollback if needed"

### Regular Maintenance
"Keep the landing page fresh:
- Update news weekly (or as events occur)
- Remove outdated events monthly
- Refresh hero image seasonally
- Review all content quarterly
- Archive old announcements"

## Common Tasks

### Changing Department Information
"Contact information and department details:
1. Go to Display page
2. Find 'Department Info' section
3. Update address, phone, email, etc.
4. Save changes

This information appears in the footer of the landing page."

### Managing Image Gallery
"To update the image gallery/carousel:
1. Go to Display page
2. Click 'Manage Gallery'
3. Upload new images or remove old ones
4. Set display order
5. Add captions
6. Save gallery"

### Embedding Videos
"To add videos to the landing page:
1. Upload video to YouTube or Vimeo
2. Copy embed code or URL
3. In Display page, add 'Video Section'
4. Paste embed code
5. Preview to ensure proper display
6. Publish"

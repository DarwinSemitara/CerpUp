# Course Management Guide

## When to Use
User asks about:
- Adding or editing courses
- Course codes and names
- Curriculum management
- Course prerequisites
- Subject assignments

## Understanding Courses in CERP

"Courses in CERP represent the subjects taught in the College of Human Ecology. Each course has:
- **Course Code**: Unique identifier (e.g., ENRP 101, FSN 1)
- **Course Name**: Full title (e.g., Introduction to Environmental Science)
- **Units**: Credit hours (typically 1-5 units)
- **Lecture/Lab Hours**: Time breakdown for different components
- **Year Level**: Which year students typically take it
- **Curriculum**: Which program it belongs to

Courses are used when creating class schedules and assigning faculty."

## Adding a New Course

### Step-by-Step Instructions
"To add a new course to the system:
1. Go to the 'Courses' page from the admin sidebar
2. Click 'Add Course' button
3. Fill in the course information:
   - Course Code (e.g., ENRP 101)
   - Course Name/Title
   - Number of Units
   - Lecture hours per week
   - Lab hours per week (if applicable)
   - Year level (1st, 2nd, 3rd, 4th)
   - Program/Curriculum
   - Course description (optional)
4. Click 'Save Course'

The course is now available for schedule generation and assignment."

## Editing Course Information

"To update a course:
1. Go to the Courses page
2. Find the course in the list (use search/filter)
3. Click the 'Edit' icon
4. Update the information
5. Click 'Save Changes'

Note: Changes to course codes may affect existing schedules. Be cautious when editing courses that are currently in use."

## Course Categories

### Lecture Courses
"Standard classroom-based courses with theoretical content. Scheduled in regular classrooms with lecture hours only."

### Lab Courses
"Courses with practical/laboratory components. These need:
- Lab facilities/rooms
- Extended time blocks (often 3-4 hours)
- Special equipment or resources
- May run concurrently with lecture component"

### Lecture-Lab Combination
"Courses with both components. The system can:
- Schedule lecture and lab separately
- Assign different rooms for each component
- Track total contact hours
- Calculate weighted units"

## Course Assignment to Faculty

"Courses are assigned to faculty during schedule generation. The system considers:
- Faculty expertise and specialization
- Previous teaching assignments
- Workload balance (total units/hours)
- Faculty availability
- Co-teaching arrangements

Admins can manually adjust assignments in the schedule page after generation."

## Viewing Course List

"To view all courses:
1. Go to the Courses page
2. Use filters to narrow by:
   - Year level
   - Program/curriculum
   - Course code pattern
   - Units
3. Sort by code, name, or year level
4. Export list if needed for reference

This helps when planning curriculum or reviewing course offerings."

## Course Sections

"Each course can have multiple sections (A, B, C, etc.) when:
- Large number of students requires multiple classes
- Different schedules are needed
- Shared courses across programs

Sections are managed during schedule creation, not in course setup."

## Important Notes

### Course Codes Must Be Unique
"Each course code must be unique in the system. Use standard format:
- Department abbreviation (ENRP, FSN, etc.)
- Course number (101, 201, etc.)
- Optional section/variant (A, B, L for lab)

Example: ENRP 101, FSN 101L"

### Units and Hours
"Total contact hours should match the unit credit:
- 1 unit = typically 1 hour lecture OR 3 hours lab per week
- 3-unit lecture = 3 hours lecture per week
- 1-unit lab = 3 hours lab per week
- 3(2-3) = 3 units with 2 hours lecture + 3 hours lab"

### Prerequisites
"While CERP tracks course information, prerequisite enforcement is typically handled by the registrar. Document prerequisites in the course description for reference."

### Inactive Courses
"Courses no longer offered can be marked inactive instead of deleted. This preserves historical schedule data while removing the course from active scheduling options."

## Common Tasks

### Bulk Course Import
"For curriculum updates involving many courses, contact IT support for bulk import assistance. Prepare a spreadsheet with all course details in the specified format."

### Course Codes Standards
"Follow CHE/UPLB standards for course coding:
- Use official department abbreviations
- Maintain consistent numbering (100s = 1st year, 200s = 2nd year, etc.)
- Add L suffix for lab components
- Use capital letters only"

### Updating Curriculum
"When updating curriculum:
1. Add new courses first
2. Mark old courses as inactive (don't delete)
3. Update course descriptions if requirements changed
4. Notify faculty of curriculum changes
5. Update documentation"

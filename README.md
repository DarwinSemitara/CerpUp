# CerpUp - Community Extension Research Portal

A comprehensive web application for managing community extension research programs, built with Flask and Firebase.

## 🚀 Quick Start

### Local Development
```bash
# Install dependencies
pip install -r requirements.txt

# Run development server
flask run
```

### Deploy to Render
```bash
# Use the quick deploy script
deploy.bat

# Or manually
git add .
git commit -m "Your message"
git push
```

**Render will automatically deploy your changes!**

## 📋 Features

- ✅ User Authentication (Firebase Auth)
- ✅ Admin Dashboard
- ✅ Faculty Management
- ✅ Research Project Tracking
- ✅ Schedule Management with Unit Configuration
- ✅ Public Engagement & TAP-HSP Sections
- ✅ Real-time Data Storage (Firestore)
- ✅ Image Upload (Cloudinary)

## 🛠️ Tech Stack

- **Backend:** Flask (Python)
- **Database:** Firebase Firestore
- **Auth:** Firebase Authentication
- **Storage:** Cloudinary
- **Deployment:** Render
- **Version Control:** GitHub
